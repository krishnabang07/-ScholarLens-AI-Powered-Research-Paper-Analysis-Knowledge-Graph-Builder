# ScholarLens - AI-Powered Research Paper Analysis & Knowledge Graph Builder

## Overview
ScholarLens is an AI-powered tool that analyzes research papers and builds knowledge graphs to visualize connections between concepts, authors, and citations.

## Features
- 📄 Research paper ingestion and parsing
- 🧠 AI-powered entity extraction
- 🔗 Knowledge graph construction
- 🔍 Semantic search and embeddings
